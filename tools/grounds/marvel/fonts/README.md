# Marvel Stadium sign sources

- **marvel_stadium_logo.png**: the venue's logo, rendered at 1920 px from Wikimedia Commons
  File:Marvel_Stadium_logo.svg. It is public domain as a text logo, and the name is a trademark. retint.py
  (sign_panels) takes the MARVEL and STADIUM letterforms from it.
- **Layout**: taken from the director's photo of the west roof sign (28 Nov 2026), rectified on the red box's
  corners. The logo's red box aspect (2.47) sets the horizontal scale, and the board is fitted to the model's
  33.4 x 7.08 m.
  - Red box: 1.43-15.27 m along, 0.69-6.39 m down.
  - White frame: 0.16 m inside the red box, 0.08 m wide.
  - STADIUM: 16.3-31.7 m along, 1.75-6.33 m down. The real sign's STADIUM is narrower than the logo's.
